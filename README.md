# Italia Bel Paese Simulator

Progetto open-world italiano basato su JavaScript e Three.js.

## Stato
Repository inizializzato. Il codice completo V0.1 esportato da ChatGPT Sites deve ancora essere importato nella cartella `dist/`.

## Distribuzione Cloudflare
Configurare Cloudflare Workers Static Assets/Pages con directory output `dist` dopo aver importato i sorgenti.

## Sicurezza
Non caricare mai chiavi API, credenziali o file `.env` nel repository pubblico.
